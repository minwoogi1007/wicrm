System Notes

12개 컨셉의 운영 적용 가이드입니다. 실전 어드민 4종은 하나를 메인으로 채택하고, 분위기 8종은 영역별 보조 톤으로 차용하는 혼합 전략을 권장합니다.

01 · 추천 조합 (실전)

메인 어드민에 15 SaaS Pro, 임원 매출 화면에 17 Stripe, 상담사용 일일 워크보드에 18 Attio Kanban, 신규/홈 화면에 16 Polaris를 배치하는 4종 조합이 가장 실전적입니다.

01b · 분위기 매핑

Bento 종합 대시보드, Brutalist 운영 모니터링, Glass AI 분석, Editorial 임원 리포트, Clay 마일리지, Terminal 시스템 관리, Y2K 캠페인, Aurora 외부 공유 리포트.

02 · 컬러 토큰

각 컨셉이 자체 토큰을 정의합니다. 두 브랜드(RENOMA, CORALIQUE) 액센트는 보존하며 데이터 색은 컨셉별 팔레트를 따릅니다.

03 · 타이포그래피

본문 Inter / Pretendard. 컨셉별로 Fraunces(Editorial), Instrument Serif(Aurora), Archivo Black(Y2K), JetBrains Mono(Brutalist · Terminal)를 추가 사용.

04 · 모션

과한 모션은 지양. Glass의 라이브 인디케이터 맥동, Aurora의 메시 그라디언트 드리프트, Y2K의 호버 리프트만 활용. 상태 전환은 180–250ms ease.

05 · 정보 밀도 단계

낮음(Aurora · Glass) → 중간(Bento · Clay · Y2K) → 높음(Brutalist · Terminal) → 읽기(Editorial). 한 사용자 세션에서 단계가 점진적으로 변하도록 라우팅 구성.

06 · 다음 단계

선호 컨셉 2–3개 선정 → 실제 데이터/컴포넌트 교체 → 다크/라이트 페어링 정의 → 기존 운영 화면(상담·교환반품·통계·마일리지)에 단계 적용.
